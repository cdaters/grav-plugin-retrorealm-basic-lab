# Bundled software and host boundary

This plugin bundles the independently maintained RetroRealm BASIC 0.7.0 Computer, including its license proposal and attribution. Exact source commit, inventory hash and file digests are recorded in basic-runtime.lock.json. Both projects await owner approval of Apache-2.0; no active license grant is asserted yet.

No third-party interpreter, historical game, data, ROM, scan, font, or production theme is included. The original Signal Station fixture is project-authored. Installed exhibits have their own rights/notices and are not relicensed by this platform.

Grav/Admin and any theme are separately installed host software, not bundled dependencies. Build/QA tools are development-only. No code is downloaded at runtime or by the build.
