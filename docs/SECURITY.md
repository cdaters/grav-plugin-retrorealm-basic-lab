# Trust boundaries and privacy

Only install reviewed local code/manifests. Admin cannot upload executable modules; draft/enable flags control catalog/routes, not static file access. For removal or a content-excluded release, physically remove the full package asset tree. Avoid overlay updates. BASIC language programs are evaluated in the independently maintained bounded interpreter, not through JavaScript eval.

Titles/manifest context are escaped; manual fragments are trusted installed HTML. Entrypoints/rulesets/URLs/routes are validated, and Admin/API prefixes and real content collisions are respected. The iframe resize bridge validates exact origin, source window, channel/version/type, token and dimensions. Host scripting privileges remain trusted: same-origin script-enabled frames cannot protect against a compromised host or replacement code. Only BASIC's evaluator/Worker separates untrusted BASIC source from host operations.

The bundled Computer has no telemetry, remote code service or subscription. Browser workspaces and exported files stay local unless shared; host page/asset requests can be logged normally. Native modules may implement different storage behavior and must document it. The platform license never grants rights to an installed game's text, data, names or artwork.

Human screen-reader and physical-touch acceptance must be recorded separately from automated viewport checks. No public security contact or tracker exists until owner-approved repository publication; do not invent one or post sensitive reports publicly.
