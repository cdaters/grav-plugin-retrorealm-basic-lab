RetroRealm BASIC manual

A small language. A real programming environment. Start with a few numbered lines and build from there.

RetroRealm BASIC is an independently developed interpreter. The BASIC Computer is its browser application; BASIC Lab is the optional collection and Grav integration. Version 0.7.0 is a local release candidate, with four compatibility subsets.

Make your first programFrom READY to RUN in a few minutes.Look up the languageStatements, functions, expressions and limits.Keep virtual mediaCassettes, files and portable copies.Build with the runtimeArchitecture, API and extension boundaries.

What this is

Programs run locally in an isolated Worker. No account, service, telemetry or connection is required. The supplied examples are original project material. You can import your own local listings. This is not a complete emulator of any historical computer; choose a profile deliberately and read its limitations.

Reading offline

This manual is ordinary HTML and CSS, with no scripts or remote assets. Use the chapter navigation, your browser’s Find command and Print. The document structure provides a starting point for a future PDF edition; no PDF is supplied.
