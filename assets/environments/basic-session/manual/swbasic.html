Simple Web Basic subset

Preserves full, case-sensitive names, while keywords are case-insensitive and matched as complete words. Reading and reading are different variables; keywords embedded inside longer names do not split them. Numeric true is 1. PRINT uses plain numbers and three spaces for comma separation. A single string INPUT preserves the response case.

Compatibility follows the inspected evaluator’s expression behavior, including eager evaluation and its repeated evaluation of function arguments/array children where applicable. That can consume extra random draws. RND with no argument advances; RND(0) repeats; other numeric arguments advance the host stream. The host seed replaces any original unseeded generator. Arrays and control flow remain the bounded shared runtime.

Explicitly unsupported vocabulary includes CLS, WHILE/WEND, RANDOMIZE, SYSTEM, KEY, CLEAR, INSTR, STRING$ and TIMER. Other shared function names outside the SWB vocabulary are not promised. Operators have the precedence described in the language chapter. Try Names that matter. This profile is a compatibility subset, not a complete clone.
